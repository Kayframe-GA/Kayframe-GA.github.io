# Kayframe GA - Portfolio Website

Portfolio website for **Kayframe GA (Monika Grabner)**, a game artist specializing in concept art, character design, and 3D sculpting.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
